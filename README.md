# Дома и аспекты натальной карты — задачник

Дом определяют по границам секторов, знак — по долготе, аспект — по углу. Все числа ниже учебные.

| № | Задача |
|---|---|
| 1 | Долгота 125°. Какой это знак и градус внутри знака? |
| 2 | Начало VI дома на 350°, VII — на 22°. Куда попадает планета на 5°? |
| 3 | Планеты на 359° и 1°. Какой между ними меньший угол? |
| 4 | Точки на 18° и 111°. Каков орбис квадрата? |
| 5 | Угол 117°. Проходит ли трин при допуске 2°? При 4°? |
| 6 | Планета и начало дома округлены до 120°. Каких данных не хватает? |

## Ответы

1. 5° Льва. Этот знак начинается на 120°.
2. VI дом. Сектор от 350° до 22° проходит через 0°.
3. 2°. Простое вычитание даёт большую дугу 358°.
4. Угол 93°, орбис к 90° — 3°.
5. При 2° нет, при 4° да. Отклонение от 120° равно 3°.
6. Нужны значения без округления и система домов. Граница сектора и планета могли округлиться до одного числа.
